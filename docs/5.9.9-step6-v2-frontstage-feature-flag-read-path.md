## 2. 当前 frontstage 消费路径

当前前台仍消费 v1/current verified source-review occurrences。

| 路径 | 当前消费点 | 口径 |
|---|---|---|
| Results page Top10 | `backend_api/app/services/specific_issue.py` 的 `build_specific_issue_rows` / `build_customer_highlight_rows`；前端 `ModuleCard` 展示 rows。 | 只统计 `_is_frontstage_countable_occurrence` 通过的 occurrence。 |
| Single review detail | `frontend/src/lib/customer-labels.ts` 的 `customerIssueTags` / `customerHighlightTags` / `customerLabelOccurrences`。 | 只展示 `isVerifiedSourceReviewOccurrence`。 |
| Raw review export | 后端 `review_analyzer/exporter.py::_build_comments_data`；前端 `analysis-results-sections.tsx::buildRawReviewsXlsx`。 | frontstage columns 只写 display occurrences；audit sheet 单独列 audit fields。 |
| Single-tag download | `frontend/src/components/analysis/download-tag-button.tsx`。 | 只下载 matching + verified source-review occurrences。 |

Step 6 没有直接改这些 live 消费点，而是新增服务层 read-path contract，明确未来接线时四条路径都必须读取同一个 selected `display_occurrences` 集合。

## 3. Feature Flag Contract

新增 `CustomerLabelV2FrontstageFlag`：

| 字段 | 作用 |
|---|---|
| `enabled` | 总开关，默认 `False`。 |
| `session_ids` | per-session 灰度。 |
| `categories` | per-category 灰度。 |
| `sub_categories` | per-sub_category 灰度，支持 `waders` 或 `outdoor/waders`。 |
| `category_sub_categories` | 精确 category/sub_category 灰度。 |
| `shadow_fixture_gate_passed` | shadow / fixture 门禁，默认 `False`；未通过时回 v1/current。 |
| `enabled_maturity_levels` | 默认只允许 `L3_sub_category` 进入 v2 frontstage read path。 |
| `rollback*` | 支持 global / session / category / sub_category rollback 回 v1/current。 |

默认行为：

```text
flag off -> v1_current
flag on but scope not matched -> v1_current
flag on but shadow fixture gate not passed -> v1_current
flag on but maturity not enabled for v2 frontstage -> v1_current
flag on + L3 waders + fixture gate PASS -> v2_shadow display_occurrences
rollback matched -> v1_current
```

## 4. Read-path Contract

新增 `build_customer_label_v2_frontstage_read_model(...)` 输出：

- `v1_current.frontstage_occurrences`
- `v2_shadow.frontstage_occurrences`
- `frontstage_occurrences`
- `frontstage_keys`
- `frontstage_consumers`
- `excluded_layers`
- `safety`

四个 frontstage consumer 都绑定同一个 selected occurrence 集合：

- `results_top10`
- `single_review_detail`
- `raw_review_export`
- `single_tag_download`

v2 被选中时，selected occurrence 必须来自 `v2_shadow.display_occurrences`，并再次满足：

- `display_allowed=True`
- `source_review_allowed=True`
- `evidence_verified=True`
- `evidence_span` non-empty
- `cluster_propagated=False`
- `legacy_fallback=False`
- `aspect_allowed=True`
- `context_allowed=True`
- `maturity_allowed=True`
- `downgrade_reasons=[]`

以下层永远不进入 frontstage selected set：

- `label_candidates`
- `audit_occurrences`
- `candidate_pool_items`
- `maturity_blocked` candidates
- `unknown_label` candidates
