## 2. 结论

当前最大问题来自三层叠加：

1. Customer Label 展示污染最重：AI 对 36 条评论批量输出 `尺码合适 / 性价比高 / 耐用可靠 / 防水可靠` 四件套，覆盖负评、未实际使用、泛泛好评和没有相应证据的评论，形成 149 个 Label 误报。
2. Customer Issue evidence/propagation 门禁失效：33 个 AI Issue occurrence 中 28 个 `Evidence Verified=false` 或无可展示 evidence，27 个 `Cluster Propagated=true`；`容易进水` 被传播到 no leaks / leak proof / 旧产品或非当前产品边界。
3. 标签粒度与召回不足：人工标注中的 `耐用性差`、`防水性差`、`尺码不准`、`气味大`、`小个子不友好` 等 Issue 漏标明显；Label 侧大量细粒度标签，如场景适用、未实际使用、轻便、大码/小个子友好、配件实用、整体满意，AI 没有覆盖。

Aspect 归类是次级但必须一起处理的问题：典型错位包括 phone case/pocket 漏水被归为整体 `waterproof`，裤长/小个子问题被归到 `boot_fit`，防滑/长时间步行问题被归成 `material`。

| `gets_hot_quickly` | 升温快/夏季闷热 | warms up quick、too hot | 新增或候选，按语境归 `temperature_rating` 或 `breathability`。 |
| `runs_too_small` | 尺码偏小 | small、snug、size up | 保留。`boot_fit` 或 `size_fit` 按 evidence。 |
| `runs_too_large` | 尺码偏大 | too big、loose、engulfed | 保留。`boot_fit` 或 `size_fit` 按 evidence。 |
| `inaccurate_size_chart` | 尺码不准 | sizing off、chart inaccurate、hard to choose size | 新增上位 issue，必要时与 runs_too_small/large 互斥或并列。 |
| `not_petite_friendly` | 小个子不友好 | petite women issue、pants long、straps loose | 新增 waders label，aspect `size_fit`。 |
| `not_plus_size_friendly` | 大码不友好 | big guy not fit、not past hips | 新增 waders label，aspect `size_fit`。 |
| `calf_area_too_tight` | 小腿位置偏小 | calves too tight | 新增，aspect `boot_fit`。 |
| `pants_too_long` | 裤长偏长 | pants are long、inseam long | 新增，aspect `size_fit`。 |
| `boots_too_stiff` | 靴子过硬 | rigid boots、very stiff | 新增，aspect `comfort/material`。 |
| `not_for_long_walks` | 非长时间步行适用 | feet pain after miles、not walking far | 新增，aspect `comfort`。 |
| `poor_traction` | 防滑性不足 | slick rocks、slippery rocks | 新增，aspect `grip`。 |
| `soft_soles` | 鞋底偏软 | soles are soft | 新增候选，aspect `grip/durability`。 |
| `pocket_not_waterproof` | 外层口袋不防水 | pocket gets wet、phone case leaked | 保留。只能归 `accessory_storage`，不得归整体 `waterproof`。 |
| `pocket_too_small` | 口袋太小 | pocket too small | 保留。 |
| `missing_accessories` | 配件缺失 | phone protector missing、hanger missing、missing parts | 新增/合并；`missing_wader_hanger` 可作为更细 alias。 |
| `accessories_not_as_advertised` | 配件与描述不符 | phone case not same as advertised | 新增，aspect `accessory_storage`。 |
| `overall_dissatisfied` | 整体不满意 | trash、would not recommend、you get what you pay for | 新增低优先标签；默认不进 Top，避免代替具体问题。 |

### 8.3 禁用/降级建议

- 禁用 broad/internal label 前台展示：`Waterproof`、`Durability`、`Product Quality`、`Quality`、`Material`、`Accessories & Storage` 等只作为 aspect，不作为 Customer Issue / Label。
- 禁用无证据四件套扩散：`尺码合适 / 性价比高 / 耐用可靠 / 防水可靠` 只能由当前评论 evidence 触发。
- 禁用 cluster propagated 在单条明细展示和 Top 计数中作为 source review occurrence；可保留为审计字段或候选池。
- 禁用未实际使用评论中的功能推断：不能标防水、耐用、抓地、保暖，除非评论明确已测试。
- 禁用 `no leaks / leak proof / kept dry / stayed dry` 触发 `water_leaks_through` issue；它们只允许触发 `keeps_water_out` highlight。

## 10. 边界 case 处理建议

| 边界 case | 处理原则 |
| --- | --- |
| 无 evidence | 不进入单条明细展示，不进 Top10；只保留候选/审计。 |
| Cluster propagated | 不当作该评论自己的标签展示，不参与 source-review Top 计数；可在审计下载中保留。 |
| no leaks / leak proof | 只能触发 `keeps_water_out` highlight，不触发 `water_leaks_through` issue。 |
| 旧产品/他牌 | 旧 waders、朋友产品、其他品牌问题不得归当前产品，除非明确“this pair/these waders”。 |
| phone case/pocket 漏水 | 归 `accessory_storage`，标签为 `pocket_not_waterproof` 或 accessories issue，不归整体 `waterproof`。 |
| 未实际使用 | 只能标 `not_used_yet`、`first_impression_positive`、试穿尺码/外观；不能推断防水、耐用、抓地、保暖。 |
| 泛泛好评 | `Great product`、`Excellent purchase` 只标 `overall_satisfied`，不得展开成四件套。 |
| 场景适用 | 钓鱼、Alaska、pressure washing、复杂地形等优先进入场景标签；只有明确功能 evidence 才同时标防水/耐用等。 |
| 好评含问题 | 允许同一条 4/5 星评论出现 Issue，前提是当前原文有负向证据。 |
| 差评含亮点 | 允许同一条 1/2/3 星评论出现 Label，前提是当前原文有正向证据。 |
| 尺码边界 | 鞋码、脚趾、小腿、靴筒归 `boot_fit`；裤长、胸围、腰/臀、肩带、小个子/大码归 `size_fit`。 |
| 透气 vs 防水 | 内部潮湿若来自汗/condensation 归 `breathability`；明确外部水进入归 `waterproof/seam_integrity`。 |
| 温度 | 保暖/冷水归 `temperature_rating`；夏天闷热可归 `breathability` 或 `gets_hot_quickly`，不可混成防水。 |
