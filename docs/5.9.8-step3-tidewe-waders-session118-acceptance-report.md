- `delete_session()` 会硬删该 session 的 `comments` / `sessions`，但不清 `review_pool`。
- 如果 `session_id=117` 或更早同产品同评论仍在当前用户下，下一次仍可命中用户历史 L1。
- 如果 `review_pool` 存在同 content_hash 且 `analyzer_version` 相同，下一次仍可命中全局缓存。
- 新 ASIN 不会绕过缓存，因为 content hash 不包含 ASIN。

4. 对这 100 条 content_hash 的 `review_pool` 执行限定清理或将 analyzed 字段置空，避免全局 L1 复用。
