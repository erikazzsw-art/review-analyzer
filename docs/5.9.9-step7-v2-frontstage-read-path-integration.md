## 3. Safety Gate

v2 只有同时满足以下条件才进入实际 frontstage：

- feature flag enabled。
- session / category / sub_category / category-sub_category scope 命中。
- shadow fixture gate PASS。
- maturity level 在 enabled list 中，默认仅 `L3_sub_category`。
- selected occurrence 来自 v2 `display_occurrences`。
- `display_allowed=True`、`source_review_allowed=True`、`evidence_verified=True`。
- evidence span 非空且可在当前评论定位。
- `cluster_propagated=False`、`legacy_fallback=False`。
- aspect/context/maturity gate 均通过。
- `downgrade_reasons=[]`。

以下内容不进入实际 frontstage：

- `label_candidates`
- `audit_occurrences`
- `candidate_pool_items`
- `maturity_blocked`
- `unknown_label`
- `candidate:*` new labels

Rollback 命中时立即回到 v1/current。
