## 2. Dry-run Contract

Dry-run helper 输入本地 review payload + feature flag/env config，输出 selected read path preview。它会强制把 `allow_runtime_shadow=False`，因此 readiness 不会临时生成 shadow，也不会用 runtime shadow 掩盖“生产尚无 stored shadow/read model”的风险。

逐条 review 检查：

- flag 是否开启。
- session/category/sub_category/category-sub_category scope 是否命中。
- shadow fixture gate 是否 PASS。
- maturity 是否允许进入 frontstage，当前默认只允许 `L3_sub_category`。
- 是否存在可消费的 stored `customer_label_v2_shadow_result`。
- rollback 命中时是否回到 `v1_current`。
- selected read path 预览是否为预期的 `v1_current` 或 `v2_shadow`。
