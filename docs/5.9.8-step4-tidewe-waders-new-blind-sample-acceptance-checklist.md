## 3. 当前 5.9.8 验收口径

前台展示字段只能使用 verified source-review occurrence：

- `Customer Issue`
- `Canonical Issue Key`
- `Customer Label`
- `Canonical Highlight Key`
- `问题标签`
- `亮点标签`
- Top10 mention count、representative evidence、单条评论明细、single-tag download

进入前台的 occurrence 必须同时满足：

- `display_allowed` 不是 false
- `source_review_allowed` 为 true
- `verified_evidence` 为 true
- 有当前评论原文可定位的 `evidence_span`
- `cluster_propagated` 为 false
- `legacy_fallback` 为 false
- `aspect_allowed` 不是 false
- `context_allowed` 不是 false

Audit/candidate 字段可以保留非确定结论，但字段名必须清晰标注为 audit：

- `Audit Customer Issue`
- `Audit Canonical Issue Key`
- `Audit Customer Label`
- `Audit Canonical Highlight Key`
- `Audit Evidence Verified`
- `Audit Cluster Propagated`

Top10、单条明细、raw review export、single-tag download 必须使用同一套 verified occurrence 口径。无 evidence、cluster propagated、legacy fallback、当前评论不可验证、context disallowed、aspect disallowed 的标签不能进入用户以为是确定结论的字段。

## 5. P0 验收重点

`water_leaks_through` 不得被以下内容污染：

- `no leaks` / `leak proof` / `kept dry` / `stayed dry`
- old pair / previous product leaked
- another brand leaked
- phone case / pouch / pocket leaked
- `can't say whether they leak` / not tested in water / not used yet

泛泛好评不得扩展成四件套：

- 防水可靠
- 尺码合适
- 耐用可靠
- 性价比高

未实际使用评论不得被错误标注为真实使用体验：

- 只能进入 context/audit 或初步印象类口径。
- 不得进入前台 Customer Label、Top10 或 single-tag download。

Mixed review 必须允许同时保留真实亮点和真实痛点：

- 好评里有真实问题，问题可展示，但必须有 evidence。
- 差评里有真实亮点，亮点可展示，但必须有 evidence。
- 不按整体评分强行单边过滤。

Aspect 归类需要重点抽查：

- size/fit：整体尺码、裤长、胸围、肩带、小个子/大码适配。
- boot_fit：靴码、脚踝、boot 部分松紧。
- material：材料质感、厚薄、PVC/布料本体。
- durability：使用后破损、耐用、撑住多次使用。
- waterproof：主产品防水、漏水、保持干燥。
- comfort：穿着舒适、闷热、活动受限。
- storage：口袋、手机袋、收纳、配件防水。
- use_case：fishing、wading、marsh、pressure washing 等真实场景成功或失败。

## 6. 错误分类

发现错误时先分类，不扩大无关重构：

- FP：前台出现不该出现的 canonical key。
- FN：当前评论有真实 evidence，但对应 key 漏召回。
- aspect 错：canonical key 对，但 aspect_key 错。
- evidence 错：标签方向对，但 evidence span 不在当前评论或证据片段不支持结论。
- 展示口径错：Top10 或单条明细混入 audit/candidate。
- 导出口径错：raw frontstage 或 single-tag download 与页面口径不一致。
- cache/生产版本问题：本地规则通过，但线上仍是旧代码、旧 raw 结构、缓存或旧 session 结果。

- `water_leaks_through` 被正向防水、历史产品、他牌、配件或未使用语境污染。
- 无 evidence、cluster propagated、legacy fallback 或当前评论不可验证标签进入 Top10、单条明细、raw frontstage 或 single-tag download。
- 未实际使用评论进入前台真实使用体验标签。
- raw/frontstage/single-tag 下载口径不一致。
