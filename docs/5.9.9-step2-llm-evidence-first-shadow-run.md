## 4. Downgrade Reasons

本轮 replay 主数据集为 v1 display mock candidates，因此主数据集没有自然降级。为覆盖 v2 verifier 降级通道，脚本和 focused tests 增加 edge cases：

| downgrade reason | count |
|---|---:|
| `context_blocked` | 2 |
| `evidence_missing` | 1 |
| `evidence_not_found` | 1 |
| `evidence_too_generic` | 5 |
| `invalid_json` | 1 |
| `source_review_blocked` | 2 |

覆盖边界：

- invalid JSON。
- evidence missing / evidence not found。
- old product / other brand leak。
- accessory phone-case / pocket leak。
- no leaks / keep dry 正向防水。
- do not keep dry 当前产品漏水。
- generic praise 不扩展成 `fits_as_expected` / `good_value_for_the_price` / `holds_up_well` / `keeps_water_out`。
- `candidate:<slug>` unknown label 只进入 candidate pool。
