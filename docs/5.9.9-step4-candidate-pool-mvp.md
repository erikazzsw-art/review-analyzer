本轮进入 candidate pool 的 edge cases：

- `unknown_label`
- `maturity_blocked`

Display occurrence 不进入 candidate pool；普通 audit-only occurrence 也不进入 candidate pool，除非同时触发 `unknown_label` 或 `maturity_blocked` gate。

## 4. Review Action Contract

Allowed action names：

- `accept`
- `reject`
- `correct_label`
- `correct_evidence`
- `needs_new_label`
- `ignore`

本轮只做 pure validation：

- 所有 action 都要求 `candidate_id` 和 `action`。
- `correct_label` 额外要求 `label_type` 与 `canonical_label_key`。
- `correct_evidence` 额外要求 `evidence_candidate`。
- `needs_new_label` 额外要求 `raw_label`。
- 不写 production DB，不产生审核状态副作用。
