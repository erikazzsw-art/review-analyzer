## 4. 修复范围

### 4.1 生成层标签修复

文件：`backend_api/app/services/specific_issue.py`

已补齐 waders content-rule occurrence，不再只靠 display filter 掩盖错误。重点覆盖：

- `water_leaks_through`
- `pocket_not_waterproof`
- `keeps_water_out`
- `fits_as_expected`
- `good_value_for_the_price`
- `holds_up_well`
- 四件套批量扩散抑制

新增/强化边界：

- `no leaks` / `leak proof` / `stayed dry` / `kept dry` / `didn't get wet` / `no issues with leaks` 只能触发 `keeps_water_out`，不能触发 `water_leaks_through`。
- phone case / sleeve / protector / pocket 漏水归 `accessory_storage` / `pocket_not_waterproof`，不能归当前产品整体 `water_leaks_through`。
- old products / other brand / historical waders / reviews or complaints about leaks 不归当前产品 `water_leaks_through`。
- 未实际使用、只试穿、只 water-tested 的评论不能批量出现 `fits_as_expected`、`good_value_for_the_price`、`holds_up_well`、`keeps_water_out` 四件套。
- 泛泛好评不能批量出现四件套。
- 负面泛评、退货、换品牌、不要买、失败使用场景不能批量出现 Customer Label。
- 每个展示标签必须有当前评论原文可定位 evidence span，且不是 `cluster_propagated`。

### 7.3 Top10 验收清单

1. `water_leaks_through` 的代表评论必须是真实当前产品漏水、渗水、内部潮湿或小漏水。
2. `water_leaks_through` 不得包含 `no leaks`、`leak proof`、`stayed dry`、`kept dry`、`didn't get wet`、`no issues with leaks`。
3. `water_leaks_through` 不得包含 phone case、phone sleeve、phone protector、pocket 漏水。
4. `water_leaks_through` 不得包含 old waders、previous pair、other brand、reviews/complaints 中提到的历史漏水。
5. 如果 50 条样本里有 phone/pocket 漏水，`pocket_not_waterproof` 应该能出现在 Issue 或单标签下载中。
6. 未实际使用、只试穿、只水测评论不得被批量计入 `keeps_water_out`、`fits_as_expected`、`good_value_for_the_price`、`holds_up_well` 四件套。
7. 泛泛好评不得被批量计入四件套。
8. 泛泛负评、退货、换品牌、不要买不得批量出现 Customer Label。
9. 每个 Top 代表评论 evidence span 必须能在评论原文里定位。
10. Top 计数不得包含 `cluster_propagated=true` 或 `evidence_verified=false` 的 occurrence。

### 7.4 单条评论明细验收清单

抽查这些语义类型：

- phone case / pocket / accessory 漏水：只能是 `pocket_not_waterproof` 或配件相关 issue，不能是 `water_leaks_through`。
- old / previous / other waders 漏水：不能是当前产品 `water_leaks_through`。
- no leaks / stayed dry / kept dry：应该是 `keeps_water_out`，不是 `water_leaks_through`。
- small leaks / seep / moisture inside：应该召回 `water_leaks_through`。
- not used yet / only tried on / only water tested：不能出现四件套扩散。
- generic negative / returned / switched brand / don't buy：不能出现 Customer Label 四件套。
- fit/size chart/petite/plus-size：aspect 必须分别落到 size/fit 相关归类，不要混成 waterproof 或 durability。
- smell/accessory/missing parts：必须进入 smell 或 accessory_storage，不要混入 durability。

## 8. Pass / Fail 判断标准

P0 FAIL：

- phone case / pocket 漏水仍进入 `water_leaks_through`。
- old / previous / other product 漏水仍进入当前产品 `water_leaks_through`。
- no leaks / leak proof / stayed dry / kept dry 仍进入 `water_leaks_through`。
- 未实际使用或泛泛好评仍批量出现四件套。
- 泛泛负评仍批量出现 Customer Label。
- Top、单条明细、单标签下载出现 `cluster_propagated=true` 或 `evidence_verified=false` 标签。
- raw review 前台字段混入 audit/candidate 标签。

可进入下一步的最低标准：

- P0 FAIL 为 0。
- 所有展示标签都有当前评论可定位 evidence。
- `water_leaks_through`、`pocket_not_waterproof`、`keeps_water_out` 三个关键标签语义正确。
