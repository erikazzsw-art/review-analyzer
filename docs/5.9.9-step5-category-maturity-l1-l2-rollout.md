## 2. Maturity Contract

| Level | 含义 | Display 边界 |
|---|---|---|
| `L0_unknown` | 未接入或未验证 category/sub_category。 | 默认不进 display；当前 explicit safe label hook 为空，候选进入 audit/candidate pool。 |
| `L1_generic` | 类目只具备通用安全展示能力。 | 仅允许 generic-safe highlights：`overall_satisfied`、`good_material_quality`、`looks_good`、`first_impression_positive`；其余进入 audit/candidate pool。 |
| `L2_category` | category 级 taxonomy/aspect 边界可用。 | 允许高置信、证据可定位、aspect/context 通过的 category-safe 基础标签；高风险或 sub_category-specific 标签进入 candidate pool。 |
| `L3_sub_category` | sub_category catalog 已通过 gold/replay 验收。 | 允许 sub_category catalog + deterministic verifier display；waders 继续走 L3。 |

初始 10 大类灰度：

| Level | Categories |
|---|---|
| `L2_category` | `home`、`3c`、`apparel`、`outdoor`、`beauty`、`kitchen` |
| `L1_generic` | `baby`、`pet`、`automotive`、`office` |
| `L3_sub_category` | `outdoor/waders` override |
| `L0_unknown` | 未命中上述配置的 category/sub_category |

数据源复用：

- 10 大类和 sub_category 归属来自 `backend_api/app/data/sub_category_categories.json`。
- 该 JSON 标记 `taxonomy_version=v1.0`，`total_sub_categories=89`，来源为 `data/taxonomy/v1.0/<category>/*.yaml`。
- 本轮没有新建后台 UI、没有 DB migration、没有生产写入。

## 3. Verifier 行为

`run_customer_label_v2_shadow` 现在会解析 maturity：

- 显式 `maturity_level` 仍可用于 focused test 或 shadow 强制降级。
- 无显式 level 时，优先匹配 `outdoor/waders -> L3_sub_category`。
- 其次使用 `sub_category_categories.json` 推断 category，再应用 10 大类 L1/L2 灰度。
- 未命中则默认 `L0_unknown`。

Display 仍需同时通过：

- evidence locatable
- confidence threshold
- aspect gate
- context/source-review gate
- maturity gate
- 非 cluster propagated
- 非 legacy fallback

unknown/new label：

- `candidate:*` 始终 `unknown_label`。
- 不会因 L2/L3 maturity 直接 display。
- 只进入本地 candidate pool / reviewed artifact。

maturity blocked：

- 不进入 display。
- 进入 audit。
- 进入本地 candidate pool artifact，便于后续审核和 maturity 升级。
