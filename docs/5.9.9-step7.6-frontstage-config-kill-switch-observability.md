## 2. Config Contract

Config 解析集中到 `resolve_customer_label_v2_frontstage_config(...)`。它支持 env-style keys 和 normalized keys，输出 raw flag、effective flag、validation errors 与 `fail_closed` 状态。

默认行为：

```text
all config unset -> enabled=False, fixture gate=False, rollback=False, kill switch=False
runtime shadow from env/config -> default False
enabled maturity levels unset -> L3_sub_category only
invalid config -> effective flag fail closed -> v1_current
```

支持字段：

| Control | Env |
|---|---|
| enabled | `CUSTOMER_LABEL_V2_FRONTSTAGE_ENABLED` |
| session scope | `CUSTOMER_LABEL_V2_FRONTSTAGE_SESSION_IDS` |
| category scope | `CUSTOMER_LABEL_V2_FRONTSTAGE_CATEGORIES` |
| sub_category scope | `CUSTOMER_LABEL_V2_FRONTSTAGE_SUB_CATEGORIES` |
| category/sub_category scope | `CUSTOMER_LABEL_V2_FRONTSTAGE_CATEGORY_SUB_CATEGORIES` |
| fixture gate | `CUSTOMER_LABEL_V2_FRONTSTAGE_SHADOW_FIXTURE_GATE_PASSED` |
| enabled maturity | `CUSTOMER_LABEL_V2_FRONTSTAGE_ENABLED_MATURITY_LEVELS` |
| global rollback | `CUSTOMER_LABEL_V2_FRONTSTAGE_ROLLBACK` |
| scoped rollback | `CUSTOMER_LABEL_V2_FRONTSTAGE_ROLLBACK_*` |
| global kill switch | `CUSTOMER_LABEL_V2_FRONTSTAGE_KILL_SWITCH` |
| scoped kill switch | `CUSTOMER_LABEL_V2_FRONTSTAGE_KILL_SWITCH_*` |
| runtime shadow | `CUSTOMER_LABEL_V2_FRONTSTAGE_ALLOW_RUNTIME_SHADOW` |

Priority:

```text
invalid config -> v1_current
global kill switch -> v1_current
scoped kill switch -> v1_current
global rollback -> v1_current
scoped rollback -> v1_current
flag off / scope miss / fixture fail / no stored shadow / maturity blocked -> v1_current
flag on + scope hit + fixture gate PASS + L3 + stored verified v2 display -> v2_shadow
```
