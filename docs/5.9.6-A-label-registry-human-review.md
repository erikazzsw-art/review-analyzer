## 2. Resolver 返回契约

人工验证时，请确认 resolver 返回的定义至少包含：

| 字段 | 人工检查点 |
|---|---|
| `key` | 只使用正式 `issue_key` 或 `highlight_key`。 |
| `label_type` | 只能是 `issue` / `highlight`。 |
| `category_keys` | 当前样本为 `["*"]`，表示通用品类范围。 |
| `sub_category_keys` | 当前样本为 `["*"]`，表示通用子品类范围。 |
| `status` | 正式前台候选只能是 `approved`。 |
| `display_label_en` / `display_label_zh` | 由 registry 统一提供展示文本。 |
| `boundary_note` | 说明该正式标签与相邻 aspect / 问题的边界。 |
| `aliases` / `alias` | `aliases` 是定义中的别名集合，`alias` 是本次解析命中的别名。 |
| `aspect_keys` | 允许挂接的 taxonomy 证据维度，不是卖家展示身份。 |
| `registry_version` | 记录本次解析使用的 registry 版本。 |
