## 二、权限约束（高风险变更）

审核页是**新增网络暴露入口 + 能改代码仓文件**，属于高风险变更：

1. **访问控制**：`/settings/label-review/*` 需要登录（`get_current_user` dependency），
   但**没有角色分级**（目前项目无 RBAC 基础设施）。
2. **风险**：任何已登录用户都能访问审核页并执行 merge（写回 YAML）。
3. **建议**：
   - 短期：在 API 层增加 user_id 白名单检查（env 变量 `LABEL_REVIEW_ALLOWED_USERS`）
   - 中期：接入项目现有的 RBAC（如有）
   - 部署时：确认 ECS nginx 没有把 `/api/settings/label-review/` 暴露到公网文档
4. **写回 YAML 的安全措施**（已实现）：
   - 只允许改 `review_fragment_label_registry.yaml` 一个文件
   - 改前自动备份 `.yaml.bak`
   - 改后立即跑 `validate_label_scope.py --dry-run`
   - 验证失败自动回滚，不落盘
   - 生成的负例回归测试追加到已有测试文件
