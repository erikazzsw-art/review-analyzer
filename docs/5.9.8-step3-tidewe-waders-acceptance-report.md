# 5.9.8 Step 3: TIDEWE waders 生产验收摘要

## 结论

本轮生产结果页只能作为当前线上展示和导出口径的只读验收样本，不作为 Step 3 最终 PASS。

原因是同批评论此前已上传过，现有 content-hash 缓存策略使用 `content + rating + category`，不包含 ASIN。换新 ASIN 但评论内容、评分、品类相同时，仍可能复用旧分析。因此本轮可以证明 Step 2 展示 gating 对当前结果有效，但不能证明新版分析链路在干净重跑后能产出正确语义标签。

## 通过项

- 重点验收行均可在结果中定位。
- 单条明细无 evidence 展示率为 0。
- 单条明细 `cluster_propagated=true` 展示率为 0。
- Top source-review occurrence 未发现 `evidence_verified=false` 或 `cluster_propagated=true`。
- 四件套标签未在无 evidence / 未使用 / 泛泛好评 / 负面评论中批量扩散。
- 同一 label 的 Top 与单条明细展示口径一致：进入展示的 occurrence 均要求 `evidence_verified=true` 且 `cluster_propagated=false`。
