# 需求：可观测性页面重构

- **日期**: 2026-06-25
- **工作量**: M（中等）
- **涉及岗位**: 前端

## 需求描述

将 `/settings/observability` 从 265 行单页重构为 5-Tab 管理后台结构，基于 Langfuse/Helicone/Portkey/Datadog 的调研最佳实践。

## 变更内容

| 项目 | 详情 |
|------|------|
| 页面结构 | 单页 → PageTabs 5-Tab（概览/成本/任务/缓存/告警） |
| 新增功能 | 时间范围选择器、模型状态灯行（60s 轮询）、Job trace 展开、成本按模型堆叠柱状图、分页 |
| API 集成 | 新集成 `/analytics/llm-costs`（之前未被前端使用） |
| 权限变更 | 从用户 sidebar 导航中移除，仅管理员通过 URL 访问 |
| 文件数 | 新增 10 个组件文件于 `frontend/src/components/observability/` |

## 涉及岗位与工时

| 岗位 | 工时 |
|------|------|
| 前端开发 | 3h（组件拆分 + 新 Tab 实现 + 调研整合） |
| 后端 | 0h（无后端改动） |
| 设计 | 0h（基于调研最佳实践自行设计） |

## 影响范围

- `/settings/observability` 页面（管理员可见）
- sidebar 导航（移除可观测性入口）
