## 需求：问评论页面对话式 UI 重构 + 多轮对话支持

**日期**：2026-06-25
**需求简称**：问评论对话式重构
**工作量评估**：L（Large）

### 需求描述

将"问评论"页面从传统表单布局改为现代 AI 对话框形式，参考 VOC Insight 等竞品的交互范式。同时后端增加多轮对话支持，允许用户针对同一组产品连续追问。

### 主要变更

1. **前端 UI 重构**：
   - 页面改为对话式布局（消息列表 + 底部输入栏）
   - 产品选择改为 Popover 弹出层（搜索 + 勾选 + tag 展示）
   - 空状态展示预设问题卡片
   - 引用评论支持折叠/展开

2. **后端多轮对话**：
   - 新增 qa_conversations / qa_messages 两张表
   - 新增对话管理 API（创建对话、发送消息、获取历史）
   - RAG 模块支持 history 参数，LLM 可感知对话上下文

### 涉及岗位及工时

| 岗位 | 工时 |
|------|------|
| 前端开发 | 6h（组件拆分 + 对话 UI + 产品选择器 + 预设卡片） |
| 后端开发 | 3h（migration + 路由 + RAG 改动） |
| 测试验证 | 1h（端到端测试多轮对话流程） |
